# TG Lead Intel - Telegram Agent & Prediction Lead Qualifier

Modern Telegram OSINT lead qualification and scoring web application for identifying high-value betting and color-trading agents, teachers, and prediction mentors.

## Features
- **Live Auto-Scraper**: Enter any Telegram `@username` or `t.me` link to automatically extract live public bio, display name, avatar, and channel/member stats.
- **Elite Quality Scoring Formula (100 Pts)**:
  - **Bio Relevance (40 pts)**: High-value agent keywords, teacher roles, platform names, monetization tags.
  - **Completeness (25 pts)**: Profile photo, bio length, display name validity.
  - **Public Evidence (20 pts)**: Verified channels, external links, SEO/advertising indicators.
  - **Reliability (15 pts)**: Clean handle structure, absence of spam flags.
- **Keyword Intelligence & Highlighting**: Automatically detects and highlights matched agent keywords inside public bios with gold tags.
- **Leads CRM Database**: Saves all analyzed profiles with quick search, filter by score level (High, Medium, Low), and one-click CSV export.
